# Rhombus Support and Developer Channels

## Developer documentation

- URL: https://developer.rhombus.com
- What's there: API reference, implementation guides (streaming, webhooks, access control, LAN streaming), rate limits, regions, the CLI, and the MCP server.

## Direct support

- General questions: the help center contact form at https://support.rhombussystems.com/hc/en-us
- Developer / API questions: `support@rhombus.com`

## GitHub (public repos)

- Org: https://github.com/orgs/RhombusSystems/
- Notable public repos: `rhombus-cli`, `rhombus-node-mcp`, `player-example`, `rhombus-api-examples-python`, `rhombus-api-examples-javascript`, `low-code-no-code`, `edgecaster-stream-converter`, `rhombus-libonvif`.
- File issues on a specific repo if the question is repo-scoped; otherwise email `support@rhombus.com`.
