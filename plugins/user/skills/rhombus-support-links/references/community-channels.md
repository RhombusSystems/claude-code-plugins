# Rhombus Community Channels

## Developer community forum

- URL: https://rhombus.community
- What's there: discussion threads, integration ideas, Q&A between Rhombus engineers and partners/developers, announcements.
- No public API / RSS feed is documented — read it in a browser.

## Direct support

- General questions: the help center contact form at https://support.rhombussystems.com/hc/en-us
- Developer / API questions: `api@rhombus.com`

## GitHub (public repos)

- Org: https://github.com/orgs/RhombusSystems/
- Notable public repos: `rhombus-cli`, `rhombus-node-mcp`, `player-example`, `rhombus-api-examples-python`, `rhombus-api-examples-javascript`, `low-code-no-code`, `edgecaster-stream-converter`, `rhombus-libonvif`.
- File issues on a specific repo if the question is repo-scoped; otherwise use the forum or email.
