# Rhombus Support Articles — Curated Link Sheet

Starting points for common end-user and admin topics. The help center search is your friend — the URLs below are known entry points, not a complete index.

**Help center home:** https://support.rhombussystems.com/hc/en-us

Maintenance note: This list needs a quarterly refresh (support.rhombussystems.com is Cloudflare-protected and can't be scraped automatically).

## Storage & Retention

- **NAS / Network Attached Storage setup** — search "NAS" in the help center. Covers supported brands (Synology, QNAP), SMB vs NFS, retention policies, and bandwidth considerations.
- **Cloud retention settings** — search "retention" for per-camera + org-level retention policy docs.
- **Storage integrations** (S3, Azure Blob) — search "storage integration".

## Video Streaming

- **Secure Raw Streams (SRS)** — search "secure raw stream" or "raw stream". Covers the Rhombus proprietary protocol for high-quality offloading.
- **RTSP bridging** — search "RTSP". Third-party camera + NVR integrations typically go through edgecaster; see the developer plugin's `rhombus-edge-streaming` skill for implementation details.
- **Video sharing (share streams + iframes)** — search "share stream".
- **Live view and playback** — search "playback" or "live view".
