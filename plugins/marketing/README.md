# Marketing Skills

Skills in this category are designed for marketing, growth, content, and brand teams.

## What belongs here

- Copywriting for ads, emails, and landing pages
- Campaign brief drafting
- Content calendar planning
- SEO content optimization
- Social media post generation
- Competitive analysis summaries
- Press release drafting

## Example skill ideas

| Skill | Description |
|---|---|
| `ad-copy` | Generate A/B ad copy variants from a product brief |
| `email-campaign` | Draft email sequences from campaign goals |
| `blog-post` | Write SEO-optimized blog posts from an outline |
| `social-post` | Generate platform-specific social posts from content |
| `press-release` | Draft press releases from announcement details |
