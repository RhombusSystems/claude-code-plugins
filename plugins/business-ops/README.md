# Business Operations Skills

Skills in this category are designed for operations, project management, and cross-functional coordination teams.

## What belongs here

- Process documentation and SOPs
- Meeting summaries and action item extraction
- OKR drafting and tracking
- Vendor evaluation templates
- Status report generation
- Workflow automation specs

## Example skill ideas

| Skill | Description |
|---|---|
| `sop-writer` | Draft Standard Operating Procedures from a process description |
| `meeting-summary` | Summarize meeting notes into decisions and action items |
| `okr-drafter` | Generate OKRs from team goals and context |
| `vendor-eval` | Create structured vendor comparison from requirements |
| `status-report` | Generate weekly status reports from bullet points |

## Adding a skill

Place new skills under `plugins/business-ops/skills/<skill-name>/SKILL.md`. See [docs/contributing.md](../../docs/contributing.md) for the full guide.
