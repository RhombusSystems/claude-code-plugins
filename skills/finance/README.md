# Finance Skills

Skills in this category are designed for finance, accounting, and financial operations teams.

## What belongs here

- Budget variance analysis
- Financial report drafting
- Expense categorization guidance
- Forecast model documentation
- Board report summaries
- Audit preparation checklists
- Cost-benefit analysis frameworks

## Example skill ideas

| Skill | Description |
|---|---|
| `budget-variance` | Analyze budget vs. actuals and draft commentary |
| `board-summary` | Summarize financial data into board-ready narrative |
| `expense-categorizer` | Categorize expenses against chart of accounts |
| `forecast-doc` | Document forecast assumptions and methodology |
| `audit-checklist` | Generate audit prep checklists from scope description |
